Comment installer :

  1. Allez dans Paramètres → Sécurité de votre téléphone.
  2. Activez "Installer des applications de sources inconnues" pour votre navigateur ou gestionnaire de fichiers.
  3. Téléchargez l'APK via le bouton ou le QR code.
  4. Ouvrez le fichier téléchargé et installez l'application.
  5. Après l'installation, vous pouvez désactiver les sources inconnues pour plus de sécurité.
